# wharton-uss-academic-journal-executive-sentiment

This repo contains the Streamlit app that the Wharton Undergraduate Statistics Society Academic Journal will make to supplement its journal entry as well as the notebooks used for data sourcing, NLP, and statistical analysis answering the following question: 

_Does the linguistic uncertainty expressed by corporate executives during quarterly earnings calls function as a leading indicator for abnormal stock return volatility in the days that follow the call — above and beyond what the company's historical volatility and hard financial results would predict?_
